# 拾影本地主题分类模型 v1

基础模型：BAAI/bge-small-zh-v1.5（智源 / FlagEmbedding，MIT）。
来源：https://huggingface.co/BAAI/bge-small-zh-v1.5

使用 Hugging Face SetFit（Apache-2.0）在 96 条自行编写的中文合成材料上微调；26 条验证材料选统一阈值 0.425。
导出 normalized CLS 编码器 ONNX FP32，并以 JSON 保存独立二元逻辑回归头；不分发 pickle、PyTorch 或训练框架。

主题：技术开发、学习资料、设计灵感、订单票据、日程事务、聊天记录、影音娱乐。最多两个标签；允许待整理。

原始模型在 72 条独立作者编写的合成盲测材料中，标签完全匹配 60 条；加入拒识与明确结构规则后，同一已知合成集回归为 65 条。
后一结果不是新的独立盲测。未对个人真实收藏进行人工标注评测，不能据此承诺个人准确率。

模型文件约 90.5 MiB；文件大小不等于运行内存。256 token 窗口、32 token 重叠，长文本覆盖全部窗口并取各主题最高分，可能夸大长材料中的次要主题。
超过 1 MiB 的输入明确返回失败，不静默截断。无足够语义的地址不会访问网页补全。

模型、分词器和分类头均在本地使用；不上传文本，不下载额外模型，不执行收藏中的代码或指令。
资产校验与上游版本见 config.json；资产重建脚本为 prepare_assets.py。
